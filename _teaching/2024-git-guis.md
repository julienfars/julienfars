A follow-on session to the Introduction to Git workshop, delivered for the Open Science Ambassadors 2024 FMRIB Graduate Course, covering how to use Git GUIs (e.g. GitHub Desktop) for local and remote repositories and version control.

Covered forking and cloning a repository, reviewing local content, addressing licence/task code/data/repository issues, creating a merge request on GitHub, raising an issue, and using the Wiki.

Course delivered in 2023 and 2024 at the OxCIN department of the UNiversity of Oxford for the MRI Graduate course.
