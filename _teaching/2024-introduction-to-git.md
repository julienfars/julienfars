Delivered as part of the WIN Open Science Ambassadors programme, this workshop introduced Git as a version control system for research code and data.

Topics covered included the "GitLost / GitFound / GitGood" workflow framing, setting up local and remote repositories, and the day-to-day Git commands needed to track changes safely.

Course delivered in 2023 and 2024 at the OxCIN department of the UNiversity of Oxford for the MRI Graduate course.
