# Julien Fars — Personal & Academic Site

Source for my personal website: **https://julienfars.github.io/julienfars/**

A single place for the research, talks, teaching, and projects that don't fit neatly into a CV — built on the [Academic Pages](https://academicpages.github.io/) Jekyll template.

## What's here

- **Publications** — peer-reviewed papers on chromatic discrimination, temporal contrast sensitivity, and retinal disease
- **Talks** — conference talks, posters, panels, and interviews, with slides where available
- **Teaching** — courses taught, with browsable slide decks
- **Portfolio** — designs and creative projects
- **Code** — one entry per public research/software repository
- **EDI** — Pride and equity, diversity & inclusion work
- **Plants** — a small houseplant photo collection (yes, really)
- **Explorations** — write-ups on things I'm learning outside of work
- **CV** — a dynamically-generated CV

## Running this locally

This repo still carries the full Academic Pages template setup (installation, `bundle`/`jekyll` commands, Docker, and the VS Code DevContainer) — see [SETUP.md](SETUP.md) for those instructions.
